## 應用程式名稱
小算盤 Calculator

## 簡短說明（Short description，繁中，上限80字）
簡單好用的計算機，支援先乘除後加減、深色模式、多幣別匯率換算。

## 完整說明（Full description，繁中，上限4000字）
小算盤是一款簡潔、好用的計算機 App。

**主要功能：**
- 標準四則運算，支援「先乘除後加減」的正確運算子優先順序
- 一鍵切換「計算」與「換算」兩個頁籤
- 內建匯率換算：支援 TWD / USD / JPY / HKD / CNY / EUR / GBP 互相換算，即時抓取最新匯率
- 深色 / 淺色主題會自動跟隨您的裝置設定切換
- 支援中文、英文介面切換

介面簡潔、操作直覺，不需要任何額外設定即可使用。

## Short description (English, ≤80 chars)
A simple calculator with correct operator precedence, dark mode, and currency conversion.

## Full description (English)
Calculator is a clean, easy-to-use calculator app.

**Key features:**
- Standard arithmetic with correct operator precedence (multiplication/division before addition/subtraction)
- Switch between "Calculate" and "Convert" tabs with one tap
- Built-in currency converter: TWD / USD / JPY / HKD / CNY / EUR / GBP, with live exchange rates
- Dark / light theme automatically follows your device setting
- Chinese / English UI toggle

Simple, intuitive, and ready to use with no extra setup.
