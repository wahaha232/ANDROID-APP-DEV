# O-193D Excel 自動核對工具

從 Excel（`.xls` / `.xlsx` / `.xlsm`）提取內嵌的第三方測試報告與 MSDS，核對部件展開表的重量、成分、報告編號、測試機構、報告日期與各項物質結果，並可選擇透過 Excel COM 自動修正。支援單檔、多檔與整個資料夾的批次核對。

## 功能

- 自動偵測含「部件名稱 / Part name」的表頭，欄位不寫死順序。
- 支援 `.xls`（xlrd）與 `.xlsx` / `.xlsm`（openpyxl），含合併儲存格。
- 從 OLE 串流、`xl/embeddings/` 提取內嵌 PDF，依 SHA-256 去重，分類為測試報告 / MSDS。
- 重量驗算：以「部件區塊」計重，避免合併或每列重複填寫造成重複加總；支援 g / mg / kg / 公克 / 公斤等單位。
- 成分驗算：以「部件 → 均質材料」區塊分組，檢查成分總和 100%，並驗證 CAS 檢查碼與內嵌 MSDS。
- 測試結果：支援 `Result / MDL / Limit / Unit` 任一欄位順序（含 Intertek 的 Result 在前）、`<` `≤` `>` `≥` `~`、負數、千分位、`㎍/cm2` 等單位差異。
- 報告日期只有命中具名欄位（Report Date / 報告日期…）才允許自動修正；fallback 日期僅警告。
- `--fix` 前自動備份、依型別寫入、修正後自動複驗。

## 安裝

需要 Python 3.10+；`--fix` 僅支援 Windows 且需安裝 Microsoft Excel。

```bat
pip install -r requirements.txt
```

## 使用方式

### 單檔

```bat
python o193d_checker.py "路徑\OOL-193D.xls" --save-report --verbose
```

或直接拖曳 Excel 檔到 `執行核對.bat`：

- 先執行核對並存出 `reports/原檔名_核對報告.txt`。
- 若有可自動修正項目，會詢問是否執行 `--fix`（保留原檔不動，原檔備份至 `backup/`，修正後檔案輸出至 `output/`）。
- 修正後會再核對一次，並另存 `reports/原檔名_核對報告_修正後複驗.txt`。

### 批次

```bat
python o193d_checker.py "D:\核對資料\A.xlsx" "D:\核對資料\B.xls" --save-report
python o193d_checker.py "D:\核對資料\2026Q4" --recursive --save-report
```

或將多個 Excel 檔／資料夾拖曳到 `批次核對.bat`：

- 每個檔案獨立處理，單一檔案失敗不會中止其他檔案。
- 批次模式會輸出「批次核對摘要」，並可用 `--save-report` 另存 `批次核對摘要.txt`。
- 名稱含「範例／範本／Example／Template」的工作表預設略過；需要時加 `--include-example`。

完整操作流程請見 [`操作文件.md`](操作文件.md)。

### 參數

| 參數 | 說明 |
| --- | --- |
| `excel_file` | 目標 `.xls` / `.xlsx` / `.xlsm` 檔案或資料夾；可一次指定多個 |
| `--save-report` | 另存 UTF-8（BOM）文字報告至 `reports/`；批次模式另存 `批次核對摘要.txt` |
| `--fix` | 以 Excel COM 寫入修正值並標紅字（保留原檔，備份至 `backup/`、輸出至 `output/`） |
| `--output-dir 路徑` | 指定比對／修正後檔案的輸出資料夾（預設為工具目錄下的 `output/`） |
| `--report-dir 路徑` | 指定核對報告與批次摘要的輸出資料夾（預設為工具目錄下的 `reports/`） |
| `--backup-dir 路徑` | 指定修正前原始檔案的備份資料夾（預設為工具目錄下的 `backup/`） |
| `--fmd-dir 路徑` | 指定三星原廠成分表（SAMSUNG FMD）資料夾，供欄位 B~J 比對 |
| `--no-fmd` | 停用欄位 B~J 與 SAMSUNG FMD 成分表的比對 |
| `--sheet 名稱` | 只核對指定工作表（套用到批次中的所有檔案） |
| `--recursive` | 輸入資料夾時遞迴搜尋子資料夾 |
| `--include-example` | 一併核對名稱含範例／範本／Example 的工作表 |
| `--verbose` | 顯示已解析的 PDF 報告與 MSDS 清單；批次模式另顯示各檔完整報告 |

### 結束碼

| 代碼 | 意義 |
| --- | --- |
| 0 | 無異常，或 `--fix` 後複驗無異常 |
| 1 | 執行錯誤（檔案、套件、工作表、COM 失敗等） |
| 2 | 仍有異常且存在可自動修正項目 |
| 3 | 仍有異常，但皆需人工確認 |

批次模式取最嚴重者：任一檔執行失敗 → 1；否則有可修正 → 2；否則有待確認 → 3；全部通過 → 0。

## 安全機制

- 自動修正一律保留原始檔案不動，先備份至 `backup/原檔名_修正前備份.xls(x)`，再將修正結果輸出至 `output/原檔名_已修正.xls(x)`；若 `output/` 內已有同名檔案且比對 `[Foxlink產品料號 + 供應商產品料號]` 相同則直接覆蓋舊版，不同料號才自動加 `_2`、`_3` 編號。
- 互動修正模式下，若修正後複驗仍有錯誤，會持續詢問是否再次修正／重新複驗，直到無錯誤或使用者取消。
- 無法建立備份或輸出檔時立即中止修正，確保原始資料安全。
- 修正後重新讀檔複驗，仍有問題時回傳 2/3 並輸出複驗報告至 `reports/`。
- 報告若配對成功但解析不到任何物質結果（例如掃描影像），會產生警告，不再默默視為通過。
- 以 Excel COM 開啟檔案前會停用巨集（`AutomationSecurity = 3`）。
- 內嵌物件有單檔與累計大小上限，避免解壓縮炸彈。
- 使用 `defusedxml` 解析未信任的 XLSX XML（openpyxl 會自動採用）。
- 全部核對、解析與修正均在本機完成，不呼叫任何 AI 模型、外部 API 或網路服務。
- 介面與操作文件使用繁體中文；來源 Excel／PDF 內的簡體字或英文內容會原樣顯示。

## 已知限制

- 掃描影像 PDF 沒有文字層，無法解析；工具會警告並要求人工核對。
- `03/04/2024` 這類同時可能是 DD/MM 或 MM/DD 的日期會標記為歧義，僅警告、不自動修正。
- 找不到 `Result / MDL / Limit` 表頭時會退回啟發式解析，並在報告中記錄「已推測欄位」的警告。
- 總重量驗算假設同一工作表屬於同一產品；若一張表包含多個產品，請人工確認。
- 百分比小數格式（0.35 = 35%）以「總和接近 1」判斷，極端比例可能誤判。
- 批次模式採循序處理，不會同時開啟多個 Excel COM 執行個體。
- 名稱含「範例／範本／Example」的工作表預設略過，避免範例資料造成大量假警告。

## 測試

```bat
python -m unittest discover -s tests -v
```

測試涵蓋單位與日期正規化、CAS 檢查碼、表頭欄位對應、重複部件/材料分組、報告編號歧義、批次目標展開與失敗隔離，以及用合成 PDF 驗證 SGS / Intertek 欄位順序、跨列式表格與 Cr6+ 單位。
