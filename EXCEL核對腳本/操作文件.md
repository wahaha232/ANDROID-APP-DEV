# O-193D Excel 核對工具 — 操作文件

本文件說明日常操作流程：單檔核對、批次核對、自動修正、輸出檔案與常見問題排除。

## 1. 適用對象與前置條件

- Windows 10/11。
- Python 3.10 以上。
- `--fix` 自動修正需要本機安裝 Microsoft Excel。
- 所有核對、解析與修正均在本機完成，不會呼叫 AI 模型、外部 API 或網路服務。
- 首次使用請先安裝套件：

```bat
pip install -r requirements.txt
```

> 解析外部 Excel／PDF 時會使用 `defusedxml`（已列入 requirements）降低 XML 風險。

## 2. 檔案放置

建議將工具與 Excel 檔分開放置，避免核對時把輸出報告與原始資料混在一起。工具本身包含：

| 檔案 | 用途 |
| --- | --- |
| `o193d_checker.py` | 主程式（單檔與批次共用） |
| `執行核對.bat` | 單檔拖曳操作 |
| `批次核對.bat` | 多檔／資料夾批次操作 |
| `requirements.txt` | 必要套件 |

## 3. 單檔核對

### 3.1 拖曳操作

1. 將一個 `.xls` / `.xlsx` / `.xlsm` 拖曳到 `執行核對.bat`。
2. 工具會提取內嵌 PDF、核對所有工作表，並顯示結果。
3. 若發現可自動修正項目，會詢問是否執行修正。

### 3.2 命令列

```bat
python o193d_checker.py "D:\核對資料\OOL-193D.xlsx" --save-report
```

常用參數：

| 參數 | 說明 |
| --- | --- |
| `--save-report` | 另存 `reports/原檔名_核對報告.txt` |
| `--fix` | 以 Excel COM 修正並標紅字（保留原檔，備份至 `backup/`、輸出至 `output/`） |
| `--output-dir 路徑` | 指定修正後檔案輸出資料夾（預設 `EXCEL核對腳本\output`） |
| `--report-dir 路徑` | 指定核對報告輸出資料夾（預設 `EXCEL核對腳本\reports`） |
| `--backup-dir 路徑` | 指定修正前原檔備份資料夾（預設 `EXCEL核對腳本\backup`） |
| `--sheet 名稱` | 只核對指定工作表 |
| `--verbose` | 顯示已解析的 PDF 與 MSDS 清單 |

## 4. 批次核對

批次模式可一次處理多個檔案、整個資料夾，或資料夾內含子資料夾。

### 4.1 拖曳多個檔案

1. 選取多個 Excel 檔，一次拖曳到 `批次核對.bat`。
2. 工具會逐檔核對，最後輸出「批次核對摘要」。
3. 若批次中有可自動修正項目，會詢問是否逐檔修正。

### 4.2 批次處理資料夾

將資料夾拖曳到 `批次核對.bat`，或執行：

```bat
批次核對.bat "D:\核對資料\2026Q4"
```

- 預設只掃描資料夾第一層。
- 需要包含子資料夾時改用命令列：

```bat
python o193d_checker.py "D:\核對資料\2026Q4" --recursive --save-report
```

### 4.3 一次指定多個檔案

```bat
python o193d_checker.py "D:\A.xlsx" "D:\B.xls" "D:\C.xlsm" --save-report
```

### 4.4 批次行為

- 每個檔案獨立處理；單一檔案失敗不會中止其他檔案。
- 自動跳過 Excel 暫存鎖檔（`~$` 開頭）與非 Excel 檔案。
- 重複指定的同一檔案只會核對一次。
- 名稱含「範例／範本／Example／Template」的工作表預設略過，避免範例資料產生假警告；需要時加 `--include-example`。
- 批次模式輸出：
  - 終端機：每個檔案的狀態與最後的批次摘要。
  - `--verbose`：另顯示每個檔案的完整核對報告。
  - `--save-report`：每檔一份核對報告，另存 `批次核對摘要.txt`。

批次摘要狀態：

| 狀態 | 意義 |
| --- | --- |
| 通過 | 無錯誤、無警告 |
| 已修正 | 已執行 `--fix` 且複驗無異常 |
| 可修正 | 有錯誤且存在可自動修正項目 |
| 待確認 | 有錯誤或警告，但需人工確認 |
| 失敗 | 檔案無法讀取、找不到工作表、COM 失敗等 |

## 5. 輸出檔案與資料夾

所有輸出預設集中存放在工具目錄（`EXCEL核對腳本\`）底下的三個資料夾，亦可用 `--output-dir`、`--report-dir`、`--backup-dir` 自行指定路徑：

| 資料夾／檔案 | 產生時機 |
| --- | --- |
| `reports\原檔名_核對報告.txt` | `--save-report` |
| `reports\原檔名_核對報告_修正後複驗.txt` | `--fix` + `--save-report` |
| `reports\批次核對摘要.txt` | 批次模式 + `--save-report` |
| `backup\原檔名_修正前備份.xls(x)` | `--fix`（自動備份修正前原檔，同名自動編號） |
| `output\原檔名_已修正.xls(x)` | `--fix`（保留原檔不動，輸出修正後檔案，同名自動編號） |

報告皆為 UTF-8（含 BOM），可用 Excel 或記事本開啟。

## 6. 自動修正注意事項

1. `--fix` 會保留原始檔案不動，先將原檔備份至 `backup\`，再將修正後的檔案輸出至 `output\`。
2. 修正後的儲存格會套用紅色字體。
3. 若 `output\` 或 `backup\` 內已有同名檔案，會自動加上 `_2`、`_3` 編號，不覆蓋既有檔案。
4. 修正後會自動重新讀檔複驗；仍有問題時結束碼為 2 或 3，並輸出複驗報告至 `reports\`。
5. 建議先用 `--save-report` 檢視報告，再用 `--fix`。

## 7. 結束碼

單檔與批次共用：

| 代碼 | 意義 |
| --- | --- |
| 0 | 無異常，或修正後複驗無異常 |
| 1 | 執行錯誤（檔案、套件、工作表、COM、輸入路徑） |
| 2 | 仍有異常且存在可修正項目 |
| 3 | 仍有異常但需人工確認 |

批次模式採「最嚴重者」：任一檔失敗 → 1；否則有可修正 → 2；否則有待確認 → 3；全部通過 → 0。

## 8. 常見問題

### 8.1 顯示「沒有核對任何工作表」

- 確認工作表含「部件名稱 / Part name」表頭。
- 若表頭名稱不同，請先調整 Excel 表頭或指定 `--sheet`。
- 批次摘要會列出是哪一個檔案失敗。

### 8.2 顯示「找不到指定的工作表」

- `--sheet` 會套用到批次中的所有檔案；若某些檔案沒有該工作表，該檔會被標示失敗。
- 批次時建議先確認所有檔案的頁籤名稱一致。

### 8.3 報告已配對但沒有測試結果

- PDF 可能是掃描影像，沒有文字層。
- 請人工核對，或提供有文字層的報告 PDF。
- 工具會產生「報告結果解析」警告，不會直接視為通過。

### 8.4 日期沒有自動修正

- 只有明確標示 `Report Date`、`Test Date`、`報告日期` 等欄位才會自動修正。
- 若工具只在頁首找到日期（可能是收樣日），會標示為警告，請人工確認。

### 8.5 檔案被鎖定

- 關閉 Excel 後重跑，或讓工具另存 `_已修正` 副本。
- 請勿在工具執行期間手動搬移或改名檔案。

### 8.6 公式讀不到值

- 若 Excel 公式從未被計算並儲存，openpyxl 會讀到空白。
- 請先用 Excel 開啟檔案、存檔一次，再重新核對。
- 工具會在報告中提示沒有快取結果的公式儲存格。

### 8.7 巨集與安全

- 自動修正時會停用巨集（`AutomationSecurity = 3`）。
- 請勿從不明來源取得 Excel 檔；工具僅針對核對流程做防護，不取代端點防毒。

### 8.8 內嵌物件過大

- 單一內嵌物件與累計大小有上限，超過會跳過並顯示警告。
- 若正常報告被誤判過大，請確認檔案是否包含異常大的附檔。

```bat

```
